## 五、配乐结构（240 s / 120 BPM / 每 16 s 一段）

| 段落 | 时间 | 能量 | 编配 |
| --- | --- | --- | --- |
| Intro | 00:00–00:16 | 低 | 稀疏底鼓 + pad + 琶音蓄势 |
| Groove | 00:16–01:04 | 中 | 加入完整鼓组、bass、8 分 hihat |
| Build | 01:04–01:52 | 升 | clap 加重、16 分 hihat、riser 渐强 |
| Drop 1 | 01:52–02:40 | 高 | impact 进入，全鼓组 + 主旋律 |
| Break | 02:40–03:12 | 落 | 收掉鼓组，pad 与主旋律留白，末端 riser |
| Drop 2 | 03:12–03:44 | 最高 | 再次 impact，全奏更厚 |
| Finale | 03:44–04:00 | 收 | 保持力度并渐弱，留出尾音 |

> 和声：Am–F–C–G（i–VI–III–VII），每和弦 8 s；pad 做 sidechain duck 制造泵感；软限幅后峰值 0.76。

## 六、复现

```bash
cd /workspace/promo
python3 make_bgm.py       # 生成 assets/bgm.wav（240 s）
python3 make_video.py     # 逐帧渲染 5760 帧并编码 MP4
python3 -m py_compile make_bgm.py make_video.py
```

素材目录 `assets/`：`home.png`、`admin_admin_plugins.png`（文件管理）、`plugins.png`、`store.png`（插件商店）、`aisettings.png`（AI 设置）、`desk.png`（工单站）、`wiki.png`，均为无头浏览器对真实站点的截图；`poster.jpg` 为成片第 28 秒抽帧。

修改字幕、镜头顺序或时长：编辑 `make_video.py` 顶部的 `SCENES` 列表；总时长 = 镜头数 × `SHOT_DUR`（默认 8 s）。修改配乐段落：编辑 `make_bgm.py` 的 `LEVELS` 与段落事件。
