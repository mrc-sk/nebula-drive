# 注册邀请码

为开放注册补上注册码校验：未填或填错注册码一律拒绝，码表由管理员维护。

| 项目 | 值 |
| --- | --- |
| 插件名 | `nd-invite-code` |
| 版本 | 1.0.0 |
| 作者 | NebulaDrive Official |
| 协议 | AGPL-3.0-only |
| 订阅钩子 | `onAuthRegisterBefore` |

## 功能

NebulaDrive 本体没有内置邀请码功能。本插件订阅 `onAuthRegisterBefore` 决策钩子，
从后台配置或数据目录 `codes.txt` 读取有效注册码；未配置任何码时自动放行，
避免装上就把注册入口锁死。配合站点的「关闭注册」设置可实现两种准入模式。

## 配置

安装后在后台「插件 → 配置」里填写 JSON（对应 `plugins.config`）。**不填任何配置时插件保持宽松/关闭状态，不会一装上就改变站点行为。

```json
{"codes": ["BERRY-2026", "TEAM-ONLY"]}
```
也可在插件数据目录新建 `codes.txt`，一行一个码，`#` 开头为注释。
宿主传入的字段名兼容 `inviteCode` / `invite_code` / `code` / `regCode`。

## 启用前须知

本插件以子进程方式运行，拥有宿主同等的文件与网络权限。请先在测试环境验证，确认策略符合预期后再在生产环境启用。

官方插件使用 Ed25519 签名，站点信任库中已内置官方公钥；安装时会在后台显示「已由受信任的发布者签名」。
