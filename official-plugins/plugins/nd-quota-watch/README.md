# 配额用量预警

当用户存储用量接近配额上限时写入预警信息，便于提前扩容或提醒。

| 项目 | 值 |
| --- | --- |
| 插件名 | `nd-quota-watch` |
| 版本 | 1.0.0 |
| 作者 | NebulaDrive Official |
| 协议 | AGPL-3.0-only |
| 订阅钩子 | `onFileUploadAfter`, `onUserQuotaChange` |

## 功能

通知/变换型插件：计算 `used / maxStorage` 占比，超过阈值时通过
`ctxPatch.quotaWarning` 注入提示并写入插件日志。默认阈值 80%，
不会拦截任何上传。

## 配置

安装后在后台「插件 → 配置」里填写 JSON（对应 `plugins.config`）。**不填任何配置时插件保持宽松/关闭状态，不会一装上就改变站点行为。

```json
{"threshold": 80}
```
阈值单位为百分比。

## 启用前须知

本插件以子进程方式运行，拥有宿主同等的文件与网络权限。请先在测试环境验证，确认策略符合预期后再在生产环境启用。

官方插件使用 Ed25519 签名，站点信任库中已内置官方公钥；安装时会在后台显示「已由受信任的发布者签名」。
