# 文件名规范化

自动清洗上传与重命名时的非法字符、路径片段与过长文件名。

| 项目 | 值 |
| --- | --- |
| 插件名 | `nd-filename-clean` |
| 版本 | 1.0.0 |
| 作者 | NebulaDrive Official |
| 协议 | AGPL-3.0-only |
| 订阅钩子 | `onFileUploadBefore`, `onFileRename` |

## 功能

变换型插件：把 Windows 非法字符、控制字符、路径分隔符与 `..` 统一替换，
去掉首尾空格与点，并截到 `maxLength`。通过 `ctxPatch.fileName` 回写，
不改变原有拒绝逻辑，可与「上传安全守卫」叠加使用。

## 配置

安装后在后台「插件 → 配置」里填写 JSON（对应 `plugins.config`）。**不填任何配置时插件保持宽松/关闭状态，不会一装上就改变站点行为。

```json
{"maxLength": 200}
```
默认 200 字符。

## 启用前须知

本插件以子进程方式运行，拥有宿主同等的文件与网络权限。请先在测试环境验证，确认策略符合预期后再在生产环境启用。

官方插件使用 Ed25519 签名，站点信任库中已内置官方公钥；安装时会在后台显示「已由受信任的发布者签名」。
