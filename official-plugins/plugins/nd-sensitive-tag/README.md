# 敏感文件标记

按关键词扫描文件名，命中后自动打上「需复核」标签，不拦截上传。

| 项目 | 值 |
| --- | --- |
| 插件名 | `nd-sensitive-tag` |
| 版本 | 1.0.0 |
| 作者 | NebulaDrive Official |
| 协议 | AGPL-3.0-only |
| 订阅钩子 | `onContentScan`, `onFileUploadAfter` |

## 功能

变换型插件：匹配到关键词时通过 `ctxPatch` 写入 `sensitive=true` 与
`tags`，并记一条告警日志。默认词表覆盖「机密 / 内部 / 私密 / 身份证 /
银行卡 / password / secret」，可自行替换。不阻断任何业务。

## 配置

安装后在后台「插件 → 配置」里填写 JSON（对应 `plugins.config`）。**不填任何配置时插件保持宽松/关闭状态，不会一装上就改变站点行为。

```json
{"keywords": ["机密", "内部", "合同"]}
```

## 启用前须知

本插件以子进程方式运行，拥有宿主同等的文件与网络权限。请先在测试环境验证，确认策略符合预期后再在生产环境启用。

官方插件使用 Ed25519 签名，站点信任库中已内置官方公钥；安装时会在后台显示「已由受信任的发布者签名」。
