NebulaDrive「智能时代」交付说明

2026-11-08 · 智能时代 V26-11.0 已推送 GitHub main（1d1a2a6），并发布 Release V26-11.0。 推送时发现远端 main 已领先 12 个提交（PBClus v2 / 签名信任库 / 备份恢复 / plugin-wiki 等），已 rebase 合并并完整保留远端历史。

一、结论：可以进，而且底子比预想的好

v2 插件平台（钩子 / 注册型扩展点 / UI 扩展点 / 后台 Setting KV / 免责确认）本来就是为「大功能可插拔」准备的，AI 只需接一层，不用动骨架。

但巡检发现一个必须先补的缺口：

后端早就有完整的 10 维搜索 GET /api/files/search 和搜索历史三接口，但前端文件页根本没有搜索框，也从未调用过它们。

所以「搜索框智能推荐」这次是先补入口、再叠智能，不是只加个推荐算法。

三、三档降级

        ↓ 没接管

        ↓ 没配 key 或调用失败

没填 key 时功能不会报错，只是「不那么聪明」。这是三档设计的主要目的。

六、怎么启用（3 步）

  1. 先不配置也能用：升级后顶栏直接出现搜索框，联想词、搜索历史、近期常用、热门、本地补全是开箱可用的（L0）。
  2. 开启 AI：后台 → AI 设置 → 打开「启用 AI 能力」→ 填 baseURL / API Key / 模型 →「测试连通性」→「保存」。之后主界面出现 AI 助手 入口，自然语言搜索、摘要、助手问答、生成式补全自动增强。
  3. 开启代码空间：同一页打开「启用代码空间」。主界面出现 代码空间 入口，选择文本文件即可在线编辑；保存会自动归档为新版本，可在文件版本里回滚。

也可以用插件完全接管模型：订阅 onAIProviderResolve 写 handled=true + result，或在 co.BEGG 注册 kind=ai，后台下拉里点名选择。写法见《插件制作手册》第 13 章。

七、必须知道的两个默认值

  • AI 总开关与代码空间开关都默认关闭，且互不依赖：只开代码空间也能用本地词法补全；只开 AI 也能用搜索/助手/摘要。
  • 按你选的「配置即用」：填了 key 之后，文件名与代码片段会发给所选模型服务商，宿主不额外弹免责确认、不强制脱敏。审计日志只记调用长度、耗时、Token、成功/失败，不记 prompt 正文。想做出域管控，用 onAIRequest 改写 ctx.prompt 或直接 deny 拦截；想完全不出域，就别填 key，装一个本地模型插件。
