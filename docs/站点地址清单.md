## 四、关于「域名」这一点

目前**只有网盘主站挂了域名**，工单站和 Wiki 仍是「IP + 端口」，没有独立域名，也不是 HTTPS。

如果要把它们也变成域名访问，推荐方案：

| 期望域名 | 指向 |
| --- | --- |
| `desk.berrywing.top` | 工单站（源站 8081） |
| `wiki.berrywing.top` | Wiki（源站 8082） |

实施前提与步骤：

1. 你在 Cloudflare 加两条 DNS 记录（CNAME 到 `berrywing.top` 或 A 到 `YOUR_SERVER_IP`），代理状态保持「已代理」。
2. 我在源站加一层按 Host 分流的反代（nginx/Caddy 监听 80，按域名转发到 8081 / 8082），并把网盘主站改到 `127.0.0.1:8080`；`nebula-tls.service` 的 443 → 80 链路保持不变。
3. 需要短暂重启主站（秒级中断），改完我逐条验证三个域名。

Cloudflare 免费版回源只支持特定端口（80 / 8080 / 8880 / 2052 / 2082 / 2086 / 2095 及 HTTPS 443 / 2053 / 2083 / 2087 / 2096 / 8443），`8081`、`8082` 不在其中，所以不能简单用「域名:端口」，必须走这层反代。

**这一步会动到线上主站监听，我没有擅自改。** 你说一声「配子域名」我就动手。
