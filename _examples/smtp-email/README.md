# SMTP 邮件插件（示例）

> 作者 **mrc-sk** · 主仓库 <https://github.com/mrc-sk/nebula-drive>
>
> 本插件是 **NebulaDrive (<https://github.com/mrc-sk/nebula-drive>)** 的扩展，
> 原作者 **mrc-sk**。

## 安装

1. 打开 NebulaDrive 后台 → 插件 → 刷新商店
2. 找到「SMTP 邮件插件」→ 安装
3. 在插件设置中填入 QQ 邮箱或 163 邮箱的 SMTP 信息
4. 完成！任何事件通知（下载完成、分享被访问、欢迎邮件）都会通过 SMTP 发送
